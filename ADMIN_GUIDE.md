# 📋 Руководство администратора сайта "Политех-ЕАО"

## 🔐 Вход в административную панель

### Как войти в админку:

1. **Или перейдите напрямую** по адресу `http://localhost:3000/admin/login`
2. **Введите учетные данные:**
   - **Логин:** admin (или созданный при установке)
   - **Пароль:** ваш пароль администратора

### 🔑 Что делать, если забыли пароль:

```bash
cd backend
node create-admin.js
```

Скрипт позволит создать нового администратора или изменить пароль существующего.

## 🏠 Главная страница админ-панели

После входа вы увидите **дашборд** с быстрым доступом ко всем разделам:

## 📝 Основные разделы и как с ними работать

### 📰 Управление новостями

**Путь:** Админ-панель → Новости

#### Добавление новости:
1. Нажмите **"Добавить новость"**
2. Заполните поля:
   - **Заголовок** - краткий заголовок новости
   - **Короткое описание** - анонс (показывается в списке)
   - **Полный текст** - подробный текст новости
   - **Изображение превью** - картинка для анонса
3. **Прикрепите файлы** (документы, фото)
4. Нажмите **"Сохранить"**

#### Редактирование:
- Нажмите **✏️** (карандаш) рядом с новостью
- Внесите изменения
- Сохраните

#### Удаление:
- Нажмите **🗑️** (корзина) рядом с новостью
- Подтвердите удаление

### 📅 Управление расписанием

**Путь:** Админ-панель → Расписание

#### Добавление группы:
1. Нажмите **"Добавить группу"**
2. Укажите:
   - **Код группы** (уникальный)
   - **Название группы**
   - **Полное название**
   - **Специальность**

#### Добавление занятия:
1. Выберите группу
2. Нажмите **"Добавить занятие"**
3. Заполните:
   - **День недели** (1-5)
   - **Номер пары** (1-5)
   - **Предмет**
   - **Преподаватель**
   - **Аудитория**

## 📁 Работа с файлами

### Поддерживаемые форматы:
- **Изображения:** JPG, PNG, GIF, WebP (макс. 5MB)
- **Документы:** PDF, DOC, DOCX, XLS, XLSX (макс. 10MB)

### Структура загрузок:
```
uploads/
├── images/          # Фото и изображения
├── documents/       # Общие документы
├── objects/         # Материально-техническое обеспечение
├── grants/          # Стипендии и поддержка
├── budget/          # Финансовые документы
├── paid-edu/        # Платные услуги
└── catering/        # Питание
```

### Рекомендации по файлам:
- **Оптимизируйте изображения** перед загрузкой
- **Используйте описательные названия** файлов
- **Проверяйте размер** перед загрузкой
- **Создавайте PDF** для важных документов

## 💡 Рекомендации по использованию

### 📝 Общие правила:

1. **Регулярно обновляйте контент** - сайт должен быть актуальным
2. **Используйте качественные фото** - они улучшают восприятие. ВНИМАНИЕ НА ТАБЛИЦУ:
Рекомендуемые цифры (ориентиры)
Это общие рекомендации, которые подходят для большинства случаев.

| Тип изображения                    | Оптимальный размер     | Оптималн. вес| Формат                 |
|------------------------------------|------------------------|--------------|------------------------|
| **Герой-изображение (Hero Image)** | 1200-2500 px по ширине | 100 - 300 КБ | **WebP** (лучший), JPG |
| **Обложка статьи / товара**        | 800-1200 px по ширине  | 50 - 150 КБ  | **WebP**, JPG          |
| **Изображения в теле статьи**      | 600-800 px по ширине   | 30 - 100 КБ  | **WebP**, JPG, PNG     |
| **Иконки, логотипы**               | До 200 px              | 5 - 20 КБ    | **SVG**, PNG           |


**Важно:** Размер в пикселях не должен превышать размер, в котором изображение отображается на экране. Загружать изображение 4000px для блока шириной 800px — большая ошибка.

3. **Проверяйте орфографию** - ошибки снижают доверие
4. **Добавляйте описания** - помогают в поиске и доступности

## 🆘 Техническая поддержка

### Если возникли проблемы:

1. **Проверьте консоль браузера** (F12 → Console)
2. **Посмотрите логи сервера** в терминале
3. **Перезагрузите страницу** (Ctrl+F5)
4. **Очистите кэш браузера**

### При ошибках загрузки:
- Проверьте размер файла
- Проверьте формат файла
- Проверьте интернет-соединение

### При ошибках сохранения:
- Проверьте заполнение обязательных полей
- Проверьте корректность данных
- Попробуйте еще раз
